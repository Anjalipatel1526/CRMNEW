# 04 — Functional Test Cases

Every test case below reports real execution status from this QA engagement:
- **Passed**: Executed and actual behavior matches expected result.
- **Failed**: Executed (via automated Vitest / `tsx` harness, API probe, or HTTP/code execution check) and observed behavior violates expected result.
- **Blocked**: Live interactive browser execution cannot run (no Playwright/browser test runner installed; DB mutations prohibited by audit rules).
- **Not Tested**: Out of read-only / non-destructive phase scope.
